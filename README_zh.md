# rebirth — 终端人生重开模拟器

Go 编写的终端人生重开模拟器。玩法致敬人生重开模拟器，内核换成计算精神病学取向的创伤记忆动力学模型。

## 特性

- **创伤动力学核心** —— 漏积分器记忆痕迹、杏仁核/前额叶耦合、再巩固正反馈，以及带迟滞的双鞍结分岔：持续逆境下进入病理吸引子很容易，脱离则须降到更低的阈值以下（治疗抵抗性的数学模拟）。
- **自相关运势** —— AR(1) 运势过程取代独立抽样：好运成串，灾祸也成串。
- **跨代血统** —— 每代继承上一代应激敏感性的亚加性比例（ψ<1），创伤会代际回响，除非被中断。
- **LLM 叙事层（可选）** —— OpenRouter 的 `stealth/ox-alpha` 负责润色关键事件、生成经 schema 校验的"命运事件"、撰写墓志铭。随机数全部由确定性核心产生；所有 LLM 输出先 clamp 再校验，失败静默回退。
- **24 职业、12 出身、200+ 事件** —— 从农民到 CEO 到数字游民、性工作者、邪教教主（需高创伤负荷解锁）。街头故事致敬国内纪录片式故事博主。

## 安装与游玩

```bash
go build -o ~/.local/bin/rebirth .
rebirth                # 交互模式
rebirth --seed 42 --auto --no-llm   # 确定性自动模式
```

| 参数 | 作用 |
|---|---|
| `--seed N` | 固定种子 |
| `--auto` | 自动选择 |
| `--no-llm` | 关闭 LLM 层 |
| `--model NAME` | OpenRouter 模型（默认 `stealth/ox-alpha`） |

设置 `OPENROUTER_API_KEY` 启用叙事层；未设置时完全离线可玩。
